UServe is a full-stack web application designed to connect users with service providers across Sri Lanka. The platform enables users to easily discover, explore, and book a wide range of local services in one place, helping bridge the gap between customers and service providers.
Features
User authentication (sign up / login)
Service browsing and search
Service provider profiles
Booking system for scheduling services
User-friendly and responsive interface
Real-time data handling (via backend services)
Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Firebase (Authentication, Firestore / Realtime Database)
Version Control: Git & GitHub
Purpose - UServe aims to simplify the process of finding reliable services in Sri Lanka by providing a centralized platform where users can connect with trusted service providers efficiently and conveniently.
Status - This project is currently under development as part of a learning and practical implementation of full-stack web development concepts.
